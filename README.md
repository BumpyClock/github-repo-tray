# GitHub Tray

A native C# / WinUI 3 notification-area app for your GitHub activity, inspired by
[RepoBar](https://github.com/steipete/RepoBar). This is an early Windows port,
not a full feature-parity release.

## First milestone

- Recent activity generated by your GitHub account.
- A native contribution heatmap for the last year, with real daily counts,
  a period total, date range, and day details.
- Your open pull requests and pull requests awaiting your review.
- Your recently pushed repositories, including accessible private repositories.
- Native tray panel, browser links, manual refresh, and periodic refresh.
- A configurable refresh interval, with visible errors and last-success data
  retained in memory when individual requests fail.

Each activity list shows up to 30 recent items. Activity comes from GitHub's
Events API, which can be delayed; it is not a contribution count or notifications
inbox. The contribution graph separately reads GitHub's GraphQL contribution
calendar, including its reported intensity levels, rather than estimating counts
from events. Counts reflect what GitHub exposes for the current account.
The app follows your Windows theme and uses native controls rather than a WebView.

Hover over a contribution day for its date and count. The graph is also a single
keyboard focus stop: use arrow keys to inspect days and Home/End to reach the
start or end of the period. A failed calendar refresh is shown explicitly and
does not prevent the other activity sections from loading.

## Prerequisites

- Windows 10 version 1809 or later; Windows 11 recommended.
- .NET 10 SDK and WinApp CLI 0.6.1 or later for development.
- Windows Developer Mode for local development-package registration.
- [GitHub CLI](https://cli.github.com/) available as `gh` on your PATH.

Sign in from your own terminal:

```powershell
gh auth login --hostname github.com
gh auth status --hostname github.com
```

GitHub Tray reuses the account chosen by `gh`. It does not retrieve, store, or
display tokens, and never runs sign-in automatically. `GH_TOKEN` and
`GITHUB_TOKEN` environment variables can take precedence over saved accounts.
To change a saved account, use `gh auth switch --hostname github.com` and refresh.
Organization SSO and credential permissions determine which private data is
available. This milestone supports GitHub.com only.

## Build and run

From the repository root:

```powershell
dotnet build .\src\GitHubTray.App\GitHubTray.App.csproj -p:Platform=x64
winapp run .\src\GitHubTray.App\GitHubTray.App.csproj --arch x64 --debug-output
```

Use project-mode `winapp run` to register and launch the development package;
do not launch the packaged executable directly. This is a development build,
not a signed installer. The initial icon is the official WinUI template icon.
This is a full-trust WinUI 3 desktop app, not UWP; MSIX and the app manifest
provide package identity and deployment, not a UWP execution model.

Closing the panel or pressing Escape hides it to the notification area. Reopen
it from its tray icon. The tray menu provides Open, Refresh, Settings, and Quit.
Use **Quit** to stop the app rather than merely close its panel.

## Tests

```powershell
dotnet test .\tests\GitHubTray.Core.Tests\GitHubTray.Core.Tests.csproj
.\scripts\Test-RuntimeIdentifiers.ps1
```

The core tests use deterministic fixtures and temporary settings files. They do
not require GitHub authentication or make network requests.
The runtime checks verify x86/x64/ARM64 selection without machine-local publish
profiles, including preservation of an explicitly supplied runtime identifier.
